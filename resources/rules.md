# Balatro rules

PC 1.0.1o-FULL. Read only the topic needed for the current question. Current observations override catalog defaults. For one named object, use `balatro://objects/<name>` (optionally `?kind=joker`, `tarot`, `seal`, etc.); its result includes a rule and topic URI.

Notation: C=Chips, M=Mult, +M adds Mult, Xn multiplies Mult by n. A hand is one play; a round is one attempted Blind; an Ante normally contains Small Blind, Big Blind and Boss Blind.
