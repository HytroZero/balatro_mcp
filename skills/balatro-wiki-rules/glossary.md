# Glossary

Use these terms consistently in specifications and diagnostics. Chapter numbers are lookup routes, not code APIs.

| Term | Meaning | Chapter |
| --- | --- | --- |
| Activation Type | Event classification; one Joker can have multiple hooks | ch03, ch05 |
| Ante | Progression unit containing Small, Big, and Boss Blinds | ch01, ch07 |
| Base Chips / Mult | Starting values from canonical hand type and level | ch02 |
| Blind | Round obstacle with an accumulated-score target | ch01, ch07 |
| Boss Blind | Final Blind of an Ante with a special rule | ch07 |
| Buy-and-use | Immediate use after purchase; legality differs from storage | ch09 |
| Cash Out | Reward display/income boundary after winning a round | ch08 |
| Chips | Additive scoring quantity ultimately multiplied by Mult | ch03 |
| Consumable | Tarot, Planet, or Spectral entity consumed on use | ch09 |
| Contains | Structural hand predicate independent of canonical hand type | ch02, ch05 |
| Copy | Ability delegation or creation of a new entity; specify which | ch05, ch09 |
| Debuffed | Own effects disabled while some structure and entity presence remain | ch04 |
| Discard | Active discard action; not every card leaving the hand | ch01 |
| Draw pile | Cards not yet drawn this round; not the full deck | ch05 |
| Edition | Base/Foil/Holographic/Polychrome/Negative modifier layer | ch04 |
| Enhancement | Bonus/Mult/Wild/Glass/Steel/Stone/Gold/Lucky layer | ch04 |
| Eternal | In-run Sticker preventing sale and destruction | ch04, ch06 |
| Face-down | Limited visibility while true card properties still resolve | ch04 |
| Face card | Normally J/Q/K; Pareidolia changes the predicate | ch05 |
| Force-selected | Card required in the action's selection | ch07 |
| Full deck | All playing-card entities still present in the run | ch05 |
| Hand | Current held cards or one play; disambiguate field names | ch01 |
| Hand level | Run-local level of a canonical hand type | ch02 |
| Held | Cards remaining in the hand after playing | ch03 |
| Independent | Joker-position ability phase following card phases | ch03 |
| Interest | Round-end balance income with a base cap | ch08 |
| Is | Exact canonical hand-type predicate | ch02 |
| Joker | Persistent ability entity in its own held area | ch05 |
| Listed probability | Displayed probability eligible for specific modifiers | ch11 |
| Mult | Scoring multiplier with additive and multiplicative modifications | ch03 |
| Negative | Edition adding capacity to the corresponding area | ch04 |
| Pack | Item/reward opening a modal offer-selection phase | ch10 |
| Perishable | In-run Sticker permanently debuffing after five rounds | ch04 |
| Planet | Consumable increasing its corresponding hand level | ch02, ch09 |
| Played | All cards in a play, including unscored incidental cards | ch02 |
| Rental | Sticker imposing a fixed purchase price and round fee | ch04, ch08 |
| Retrigger | Additional card-ability activation in a specified phase | ch03 |
| Round | Combat and settlement boundary for an entered Blind | ch01 |
| Scoring cards | Ordered entity set participating in card scoring | ch02 |
| Seal | Gold/Red/Blue/Purple modifier layer | ch04 |
| Seed | One input determining the run's random process | ch11 |
| Showdown | Special Boss class at multiples of Ante 8 | ch07 |
| Stake | Cumulative difficulty setting | ch06 |
| Stake Sticker | Collection win record, distinct from in-run Stickers | ch04 |
| Tag | Skip reward with immediate or delayed resolution | ch10 |
| Voucher | Permanent run upgrade in a base/upgrade pair | ch10 |
| XMult | Multiplicative change to Mult; execution position matters | ch03 |
